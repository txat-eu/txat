# Txat

Real-time web and Android chat platform for Spanish- and Portuguese-speaking communities.

- **Web App:** [https://txat.eu](https://txat.eu)
- **Developer:** Jolasgela
- **Tech Stack:** React + Vite, Flutter/Dart, Go microservices, InspIRCd over TLS, PostgreSQL, Redis, MinIO.

## Support & Feedback

For bug reports, room suggestions, or moderation inquiries, please open an issue in this repository or contact us through [txat.eu](https://txat.eu).
